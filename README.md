[Specification](https://riscv.org/specifications/ratified/)

## Building and running

### Prerequisites

- `podman`/`podman-compose` or `docker`/`docker-compose`
- `just` task runner

### Build, run, test

#### Build release version

```Shell
just build
```

#### Test

```Shell
just test
```
